# 报名表单显示/隐藏控制指南

## 快速开始

通过数据库配置，你可以随时控制报名页面中报名表单的显示/隐藏，无需修改代码。

---

## 第一步：部署云函数

在微信开发者工具中：

1. 找到 `cloudfunctions/getGlobalConfig` 文件夹
2. 右键点击该文件夹
3. 选择"上传并部署：云端安装依赖"
4. 等待上传完成

---

## 第二步：创建数据库集合

1. 点击开发者工具顶部的"云开发"按钮
2. 进入"数据库"标签
3. 点击"+"号，创建新集合
4. 集合名称输入：`global_config`
5. 点击"确定"

---

## 第三步：设置集合权限

1. 点击 `global_config` 集合
2. 点击"权限设置"标签
3. 设置为：
   - **所有用户可读**：允许（这样前端才能读取配置）
   - **所有用户可写**：关闭（只有管理员能修改）

---

## 第四步：添加配置记录

1. 在 `global_config` 集合中，点击"添加记录"
2. 切换到"JSON"模式
3. 粘贴以下内容：

```json
{
  "_id": "registration_form",
  "key": "registration_form",
  "name": "报名表单配置",
  "visible": true,
  "description": "控制报名页面中报名表单的显示/隐藏",
  "updateTime": "2026-01-23 12:00:00"
}
```

4. 点击"确定"保存

---

## 第五步：测试功能

1. 在小程序中打开报名页面（featured-detail）
2. 应该能看到报名表单正常显示

---

## 如何控制显示/隐藏

### 隐藏报名表单

1. 打开云开发控制台
2. 进入"数据库" → `global_config` 集合
3. 找到 `_id` 为 `registration_form` 的记录
4. 点击"编辑"
5. 将 `visible` 字段改为 `false`
6. 点击"确定"保存
7. 刷新小程序页面，报名表单将消失

### 显示报名表单

1. 打开云开发控制台
2. 进入"数据库" → `global_config` 集合
3. 找到 `_id` 为 `registration_form` 的记录
4. 点击"编辑"
5. 将 `visible` 字段改为 `true`
6. 点击"确定"保存
7. 刷新小程序页面，报名表单将显示

---

## 效果展示

### 当 `visible: true` 时
报名页面会显示完整的报名表单，包括：
- 立即报名标题
- 姓名输入框
- 手机号输入框
- 备注输入框
- 提交报名按钮

### 当 `visible: false` 时
报名页面只显示：
- 轮播图
- 课程信息
- 报名表单完全隐藏

## 常见问题

### Q1: 修改配置后没有生效？
**A:** 用户需要刷新页面（下拉刷新或重新进入页面）才能看到最新配置。

### Q2: 提示"获取配置失败"？
**A:** 请检查：
1. 云函数 `getGlobalConfig` 是否已成功部署
2. 数据库集合 `global_config` 是否已创建
3. 集合权限中"所有用户可读"是否已开启

### Q3: 能否设置定时显示/隐藏？
**A:** 目前需要手动修改数据库配置。如需自动化，可以编写定时触发器云函数来实现。

### Q4: 如何针对特定用户显示/隐藏？
**A:** 当前版本是全局配置，所有用户看到的效果一致。如需针对特定用户，需要修改代码逻辑。

## 扩展功能

你可以用同样的方法控制其他功能模块的显示/隐藏，例如：

```json
{
  "_id": "comment_section",
  "key": "comment_section",
  "name": "评论区",
  "visible": true,
  "description": "控制评论区的显示"
}
```

只需在对应的页面代码中添加类似的配置读取逻辑即可。
