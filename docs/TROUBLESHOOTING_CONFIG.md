# 全局配置故障排查指南

## 问题：显示"全局配置不存在，使用默认值"

如果你在控制台看到这个提示，说明云函数无法从数据库获取配置。按照以下步骤排查：

---

## 排查步骤

### 1. 重新部署云函数（最重要！）

**你必须先重新部署云函数，才能看到最新的调试日志**

1. 在微信开发者工具中找到 `cloudfunctions/getGlobalConfig` 文件夹
2. 右键点击该文件夹
3. 选择"上传并部署：云端安装依赖"
4. 等待上传完成（看到"上传成功"提示）

### 2. 检查数据库记录

打开云开发控制台 → 数据库 → `global_config` 集合，确认：

#### 检查点 1：记录的 `_id` 字段
- ✓ 正确：`_id` 的值是 `registration_form`（字符串）
- ✗ 错误：`_id` 是其他值，或者是自动生成的一长串字符

**如果 _id 错误，请删除该记录并重新添加：**

```json
{
  "_id": "registration_form",
  "key": "registration_form",
  "name": "报名表单配置",
  "visible": true,
  "description": "控制报名页面中报名表单的显示/隐藏"
}
```

#### 检查点 2：`visible` 字段的类型
- ✓ 正确：`visible` 是布尔类型（true 或 false），**不带引号**
- ✗ 错误：`visible` 是字符串类型（"true" 或 "false"），带引号

**错误示例：**
```json
{
  "visible": "true"  // ✗ 错误：这是字符串
}
```

**正确示例：**
```json
{
  "visible": true  // ✓ 正确：这是布尔值
}
```

### 3. 检查数据库权限

1. 打开云开发控制台 → 数据库 → `global_config` 集合
2. 点击"权限设置"标签
3. 确认设置为：
   - **所有用户可读**：✓ 已开启
   - **所有用户可写**：✗ 已关闭

### 4. 查看调试日志

完成上述步骤后，刷新小程序页面，然后：

#### 在小程序端查看日志：
1. 打开微信开发者工具的"控制台"标签
2. 查找以 `=====` 开头的日志
3. 应该能看到类似这样的输出：

```
===== 开始加载全局配置 =====
请求参数 key: registration_form
云函数完整返回结果: {...}
res.result.code: 0
res.result.data: {...}
✓ 配置获取成功
visible 字段值: true
```

#### 在云函数端查看日志：
1. 打开云开发控制台
2. 进入"云函数" → "日志"
3. 选择 `getGlobalConfig` 云函数
4. 查看最新的日志输出

---

## 常见问题及解决方案

### 问题 1：云函数日志中显示 "result.data: undefined"

**原因**：数据库中找不到 `_id` 为 `registration_form` 的记录

**解决方案**：
1. 检查数据库中记录的 `_id` 字段是否正确
2. 确保 `_id` 的值完全是 `registration_form`（区分大小写）
3. 如果 `_id` 不正确，删除记录并重新添加

### 问题 2：日志显示 "配置不存在"

**原因**：云函数查询数据库时返回空结果

**解决方案**：
1. 确认数据库集合名称是 `global_config`（全小写，中间是下划线）
2. 确认记录的 `_id` 是 `registration_form`
3. 检查数据库权限，确保"所有用户可读"已开启

### 问题 3：报名表单一直显示，无法隐藏

**可能原因**：
- `visible` 字段是字符串 `"false"` 而不是布尔值 `false`
- 云函数没有正确部署

**解决方案**：
1. 在数据库中编辑记录，确保 `visible` 是布尔类型
2. 重新部署云函数
3. 清空小程序缓存：开发者工具 → 清除缓存 → 全部清除

### 问题 4：提示"云函数调用失败"

**原因**：云函数没有部署或部署失败

**解决方案**：
1. 确认 `cloudfunctions/getGlobalConfig` 文件夹存在
2. 确认文件夹中有 `index.js` 和 `package.json`
3. 右键点击文件夹，选择"上传并部署：云端安装依赖"
4. 查看上传日志，确认没有错误

---

## 验证配置是否生效

### 测试步骤：

1. **设置为隐藏**
   - 在数据库中将 `visible` 改为 `false`
   - 刷新小程序页面
   - 报名表单应该完全消失

2. **设置为显示**
   - 在数据库中将 `visible` 改为 `true`
   - 刷新小程序页面
   - 报名表单应该正常显示

---

## 如果以上方法都不行

请提供以下信息以便进一步诊断：

1. 小程序控制台的完整日志（从 `===== 开始加载全局配置 =====` 开始）
2. 云函数日志中 `getGlobalConfig` 的输出
3. 数据库中 `global_config` 集合的截图
4. 云函数是否部署成功的确认
